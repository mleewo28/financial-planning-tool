
# Personal Financial Planning Tool

## Project Overview

The **Personal Financial Planning Tool** is an interactive Excel-based application developed using **Visual Basic for Applications (VBA), macros, and UserForms** to simplify personal financial management.

The application allows users to track income and expenses, establish financial goals, analyze spending patterns, and receive personalized financial guidance through a centralized platform.

By combining financial analysis with automated workflows and interactive interfaces, this project aims to make personal budgeting more accessible, organized, and efficient.

## Key Features

### 1. Income and Expense Tracking
- Record and manage income and expense transactions.
- Categorize expenses to maintain an organized financial history.
- Track financial activity over time.
- Simplify transaction management through VBA-powered interfaces.

### 2. Personalized Financial Planning
- Establish and manage personal financial goals.
- Organize financial priorities using a dedicated planning interface.
- Support long-term financial planning and budgeting.

### 3. Spending Analysis and Visualization
- Analyze expenses across different spending categories.
- Generate summaries of spending distributions.
- Identify spending patterns to better understand financial habits.
- Provide insights into how income is allocated across expenses.

### 4. Financial Advice
- Access personalized budgeting guidance.
- Compare spending patterns against recommended financial allocations.
- Identify opportunities to improve financial management.
- Support informed financial decision-making.

### 5. Interactive User Interface
- Navigate the application using VBA UserForms.
- Automate repetitive financial tracking tasks using macros.
- Simplify data entry and financial reporting.
- Access financial planning features through a centralized Excel workbook.

## Technologies Used

| Technology | Purpose |
|------------|---------|
| Microsoft Excel | Financial data storage, calculations, and reporting |
| VBA | Application logic and workflow automation |
| VBA UserForms | Interactive user interfaces and data entry |
| Excel Formulas | Financial calculations and spending summaries |

## Project Structure

The Excel workbook contains five main worksheets:

- **Introduction:** Main application landing page.
- **Expenses&Incomes:** Financial transaction tracking.
- **Goals:** Personal financial planning and goal management.
- **Output:** Financial summaries and analysis.
- **Financial Advice:** Budgeting guidance and recommendations.

## Getting Started

### Prerequisites

- Microsoft Excel desktop application with VBA support.
- A compatible operating system and Excel configuration for running macros.

### Installation

1. Download `financial_planning_tool.xlsm` from this repository.
2. Open the workbook in Microsoft Excel.
3. Review the workbook and enable macros. 
4. Navigate through the application to explore its financial planning features.

**Note:** The application requires macro-enabled Excel functionality and may not work in Excel for the web.
